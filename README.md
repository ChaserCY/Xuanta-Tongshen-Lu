## 关卡简介

《玄塔通神录》是一座层层向上的**箱庭式爬塔关卡**。玩家自底层起步，在箱庭场景中探索、拾取、战斗，
赚取「通宝」与「通神积分」，逐层突破分段奖励，最终登顶伐天、以凡骨之躯破界。

## 玩法特色

### 一、箱庭探索，肉鸽爬塔

开箱拾取、随机成长，每局构筑都不重复。场景中散落可交互宝箱与道具，
按 `F` 拾取，按 `Z` 使用光标标点定位关键物品。

<p align="center">
  <img src="images/01-hakoniwa-roguelike.jpg" alt="箱庭探索，肉鸽爬塔" width="760">
</p>

### 二、获取积分，赚取通宝

核心资源循环：通关与战斗产出积分，积分兑换通宝。宝箱可选择**立即打开**，
或**锁死**——本次不开、下次打开收益更高，形成风险与收益的取舍。

<p align="center">
  <img src="images/02-earn-points.jpg" alt="获取积分，赚取通宝" width="760">
</p>

### 三、分段奖励，层层突破

每突破一个分段，可在奖励节点一次领取三类成长资源：

| 奖励类型 | 说明 |
| --- | --- |
| 获取武器 | 补充当前武器系，按 `C` 打开装备界面 |
| 获取通分和通宝 | 关卡货币，用于商店消费 |
| 获取通神积分 | 通神积分，冲击更高评价 |

<p align="center">
  <img src="images/03-tiered-rewards.jpg" alt="分段奖励，层层突破" width="760">
</p>

### 四、登顶伐天，反骨破界

登顶即为终局挑战 —— 逆神而伐天，以凡骨破界。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| `F` | 拾取 / 交互（打开、锁死） |
| `C` | 打开装备界面（当前武器系） |
| `H` | 新手教程 |
| `G` | 商店 |
| `U` | 切换职业（次数 1/1） |
| `Y` | 切换摄像机视角 |
| `Z` | 光标标点（2/2） |

## 目录结构

```
.
├── images/          # 封面、玩法截图、加载背景、成就徽记
├── *.gil            # 关卡工程文件（按日期迭代，早期原型 → 成品）
└── 图.zip           # 原始图片素材包
```

`.gil` 文件按 `月.日` 命名，记录了关卡从早期原型到最终成品的完整迭代过程：

| 阶段 | 代表文件 | 说明 |
| --- | --- | --- |
| 原型期 | `10.16` ~ `10.31` | 场景搭建与基础玩法验证 |
| 成长期 | `11.1` ~ `11.17` | 系统接入、数值调整 |
| 成熟期 | `11.18` ~ `11.27` | 玩法完善、表现优化 |
| 完成期 | `Final_build.gil` / `12.3.gil` | 打包定版 |

## 文件格式

| 扩展名 | 说明 |
| --- | --- |
| `.gil` | 原神 UGC 关卡工程文件，在千星奇域编辑器中导入 / 打开 |
| `.gia` | 原神 UGC 资源 / 逻辑片段文件 |
